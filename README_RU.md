# TG UNLOCK — персонализированная сборка Flowseal/tg-ws-proxy

**Автор модификации и упаковки:** Artem_Sukhinin  
**Основа:** [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy)  
**Лицензия исходного проекта:** MIT (см. `LICENSE` в оригинальном репозитории).

> Это bootstrap-проект для воспроизводимой сборки Windows EXE на GitHub Actions. Он скачивает актуальный исходный код оригинального репозитория при запуске сборки, сохраняет оригинальные уведомления и лицензию, а собранный файл переименовывает в `TG_UNLOCK.exe`.
>
> Важно: этот архив не содержит копию исходников Flowseal, потому что исходный репозиторий загружается во время GitHub Actions. Переименование файла не меняет внутренний заголовок/интерфейс приложения. Для полноценного ребрендинга окна, иконки и меню трея нужны точечные изменения исходников upstream; они намеренно не имитируются здесь.

## Сборка EXE

1. Создайте на GitHub новый публичный или приватный репозиторий, например `TG-UNLOCK`.
2. Распакуйте архив и загрузите **все файлы и папки** в корень репозитория.
3. Откройте вкладку **Actions** и разрешите запуск GitHub Actions, если GitHub попросит.
4. Запустите workflow **Build TG UNLOCK (Windows x64)** через **Run workflow**.
5. После завершения откройте результат запуска и скачайте artifact `TG_UNLOCK-windows-x64`.
6. Внутри архива будет `TG_UNLOCK.exe` и файл `UPSTREAM-LICENSE.txt`.

Сборка использует код Flowseal без изменения логики прокси. Проверяйте исходники и готовый EXE перед запуском; сторонний форк не является официальным релизом Flowseal.
